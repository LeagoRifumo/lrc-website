# LRC analyst research layer

One JSON file per covered company (`<TICKER>.json`, JSE tickers end in `.JO`). When a file exists, the one-page
summary (`stock.html?t=<TICKER>`) shows the analyst's own view on top of the automated scanner data, labelled with the
analyst's name and date. Only the analyst (or the Weekly Research Agent under the analyst's instruction) edits these.
Fields are optional; leave out anything you don't have. Lists are bullet points.
