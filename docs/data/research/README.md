# LRC research layer

One JSON file per company (`<TICKER>.json`, JSE tickers end in `.JO`), written automatically by the LRC research agent
(see `agents/research_agent.md`) from company results, investor-relations pages, SENS / SEC filings and news, with sources.
When a file exists, the one-page summary (`stock.html?t=<TICKER>`) shows it on top of the live scanner data.
